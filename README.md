# GitBot

## Overview
This repository contains the GitBot project, designed to interact with GitHub and provide a user-friendly dashboard.

## Basic Setup
1. Clone the repository.
2. Open `GitBot.xcodeproj` in Xcode (macOS 13.0+ required).
3. The project has no external dependencies - it uses SwiftUI.
4. Build and run the project with `Cmd+R`.

## Current Features
- Native macOS SwiftUI application
- Navigation-based dashboard interface
- Three main sections: Dashboard, Repositories, and Fine-Tuning
- App sandboxing with network client entitlements
- Minimum window size: 800x600

## Planned Features
- Advanced features (in progress).
- Real-time metrics tracking (in progress).

## Getting Started
To get started with GitBot, follow the steps above and refer to the project's documentation for more details.
